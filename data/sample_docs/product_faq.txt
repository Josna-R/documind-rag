What is the data retention policy? Customer data is retained for 90 days
after account cancellation, after which it is permanently deleted from
production systems. Backups are purged within 120 days.

How does the platform handle rate limiting? API requests are limited to
1000 requests per minute per API key on the Pro plan, and 100 requests per
minute on the Free plan. Exceeding the limit returns an HTTP 429 response
with a Retry-After header.

What security certifications does the platform hold? The platform is
SOC 2 Type II certified and undergoes annual third-party penetration
testing. All data is encrypted at rest using AES-256 and in transit using
TLS 1.3.

What is the uptime guarantee? The Enterprise plan includes a 99.9% uptime
SLA measured monthly, with service credits issued for any month that falls
below that threshold.
